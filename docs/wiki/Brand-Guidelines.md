# Brand Guidelines

## Typography

- Headings: Space Grotesk
- Body: Inter

## Color System

| Token | Use |
|---|---|
| --cyan-accent | Primary accents and action signals |
| --var-bg | Page background |
| --var-card | Surface background |
| --var-main | Primary text |
| --var-dim | Secondary text |

## UI Direction

- Keep contrast high in both dark and light modes.
- Keep spacing consistent across cards and sections.
- Prefer clarity over decorative complexity.
