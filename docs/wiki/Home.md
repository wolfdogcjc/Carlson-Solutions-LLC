## 🏢 About This Repository

This repository hosts the public-facing website for **Carlson Solutions LLC**, a technology and consulting firm serving Chisago County, Minnesota and surrounding areas.

**Core Services:**
- IT Management (UniFi networking, server administration)
- Security Consulting (physical security audits)
- Energy Auditing (building envelope and electrical systems)
- Office Tech Setup (workstation and peripheral configuration)
- UniFi Protect Setup (camera and NVR configuration)
- Custom Project Requests (scoped technical solutions)

**Repository type:** Static single-page website (HTML/CSS/JS)
