## 🏢 About This Repository

This repository hosts the public-facing website for **Carlson Solutions LLC**, a technology and consulting firm serving Chisago County, Minnesota and surrounding areas.

**Core Services:**
- IT Management (UniFi networking, server administration)
- Security Consulting (physical security audits)
