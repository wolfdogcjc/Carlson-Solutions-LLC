# Service Logic

## Definitions

| Service | Short definition | Typical outcome |
|---|---|---|
| IT Management | Network and systems configuration support | Stable, managed infrastructure |
| Security Consulting | Physical and operational security review | Actionable risk reduction |
| Energy Auditing | Efficiency analysis of systems and usage | Lower operating waste |
| Office Tech Setup | Workstation and peripheral setup | Faster, cleaner operations |
| UniFi Protect Setup | Camera/NVR provisioning and tuning | Reliable surveillance workflows |
| Custom Project Requests | Scoped work outside standard offerings | Tailored technical delivery |
