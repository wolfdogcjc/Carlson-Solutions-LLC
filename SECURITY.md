# Security Policy

## Report a Vulnerability

Do not open public issues for vulnerabilities.

- Email: contact@carlsonsolutionsmn.com
- Subject: [SECURITY] Vulnerability Report
- Include:
  - Description
  - Reproduction steps
  - Impact

## Response Targets

- Acknowledgement: within 48 hours
- Initial remediation plan: within 7 business days

## Supported Version

Only the current production content from main is supported.

## Secret Handling

- Never commit credentials or private keys.
- Never expose tokens in client-side JavaScript.
- Rotate any leaked secret immediately.
